# 青花侦探 Blue & Trace

一个面向探究式学习的可解释 AI 青花瓷研究工具。

**在线演示：** [blue-trace-detective.netlify.app](https://blue-trace-detective.netlify.app)

用户不只问“这是什么”，而是继续追问：

- 为什么这件青花瓷会出现这种纹饰？
- 这类纹饰与哪些年代、器型同时出现？
- 图像观察与馆藏记录是否一致？
- 哪一步是有来源的事实，哪一步只是解释？

项目把 **视觉观察、馆藏检索、关系图遍历、跨记录比较、冲突检测和问题链生成** 串成一条可查看的研究流程。

## 数据规模

当前内置 **1,200 条故宫博物院青花陶瓷记录**：

| 来源 | 记录数 | 说明 |
| --- | ---: | --- |
| 故宫博物院数字文物库 | 1,200 | 陶瓷分类，正式名称明确含“青花”；全部具有唯一馆藏编号、年代、图片和来源链接 |

这 1,200 条记录具有 1,200 个不同的完整学名，不使用“瓶”“罐”“盘”等泛称充数。例如：

- 永乐款青花缠枝莲纹压手杯
- 弘治款青花莲池游龙纹碗
- 宣德款青花海水云龙纹高足碗
- 万历款青花五彩鱼藻纹蒜头瓶

每条记录包含：

- 故宫博物院正式文物名称、器型、馆藏编号
- 朝代与帝王纪年、标准化年代桶
- 材质与技法
- 从正式名称提取的纹饰线索、器型线索
- 文化传统标签
- 观察、工艺、年代与不确定性说明
- 带文本依据和故宫博物院来源链接的关系数组

境外博物馆中缺少准确中文专名的泛化记录已从主数据中删除。

## 核心流程

```text
用户问题 / 图片
      │
      ▼
图像色彩观察（可选视觉模型候选）
      │
      ▼
从 1,200 条完整学名馆藏中定位分析对象
      │
      ▼
文物 ── 纹饰 ── 年代
  │       │
  └──── 器型 ── 年代
      │
      ▼
跨记录比较 + 冲突保留
      │
      ▼
证据报告 + 下一步问题链
```

### 可解释 Graph-RAG

- 每条文物关系都保存 `predicate / object / evidence / sourceUrl / kind`
- 纹饰和器型关系会回溯到文物正式名称中的对应词
- 跨记录统计明确标注为“当前馆藏语料分布”，不冒充完整艺术史统计
- 前端的证据面板可打开故宫博物院对应名称的馆藏检索页面

### Agent 执行记录

系统返回真实工具执行轨迹：

1. 解析问题中的对象、纹饰、器型与年代假设
2. 定位馆藏对象
3. 遍历纹饰、器型与年代关系
4. 对同类记录做跨来源比较
5. 生成可以继续追问的问题链

### 多模态输入

未配置模型密钥时：

- 浏览器端读取上传图片
- 提取平均色彩、蓝色像素比例和亮度
- 明确标注“只描述颜色，不据此鉴定年代或真伪”

配置 DeepSeek `deepseek-flash` 或其他兼容 OpenAI Chat Completions 的视觉模型后：

- 视觉模型返回纹饰、器型、颜色与置信度候选
- 候选必须来自当前知识语料允许的标签集合
- 视觉候选与馆藏标签冲突时保留分歧，不强制统一

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 [http://localhost:3000](http://localhost:3000)。

类型检查和生产构建：

```bash
pnpm typecheck
pnpm build
```

## 可选模型配置

公开证据图谱演示不需要密钥。若需启用视觉识别和证据约束的叙事综合：

```bash
cp .env.example .env.local
```

配置：

```env
LLM_API_KEY=
LLM_BASE_URL=https://api.deepseek.com
LLM_VISION_MODEL=deepseek-flash
LLM_TEXT_MODEL=deepseek-flash
```

模型只接收当前问题和已检索证据；系统提示要求不得补写输入中没有的史实。

## 数据更新

从故宫博物院数字文物库重新生成完整学名语料：

```bash
pnpm data:blue-white:dpm
```

脚本会筛选陶瓷分类中名称明确含“青花”、长度不少于 6 个汉字、带图片和馆藏编号的记录，并保证名称和馆藏 ID 均不重复。

## 数据边界

- 馆藏元数据不等于独立鉴定结论。
- 纹饰与器型关系从正式学名中提取，名称中没有写出的图像细节不会被补造。
- 馆藏元数据与影像权利归故宫博物院所有；项目保留并展示原始馆藏链接，用于非商业比赛研究与核对。
- 正式名称是馆藏编目名称，不等同于独立鉴定证书。
